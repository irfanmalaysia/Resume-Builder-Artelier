# ArtelierIrfan Resume Builder

Laman web pembina resume (BM / English). Semua fail di sini ialah laman web lengkap.

- `index.html` — aplikasi (edit teks, warna, senarai tugas, analitik di sini)
- `support.js` — enjin paparan aplikasi
- `vendor/` — React & jsPDF (disimpan sendiri, tidak bergantung pada laman luar)
- `assets/logo.png` — logo & ikon laman

Untuk kemas kini: muat naik `index.html` baharu ke repositori ini (Add file → Upload files).
